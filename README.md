# Car Check

Сайт для перевірки авто перед покупкою: користувач обирає марку, модель, рік, двигун і тип коробки (або вставляє посилання на оголошення) й отримує звіт з типовими проблемами двигуна та коробки.

## Структура

```
index.html              — головна сторінка: вибір авто, посилання або текст оголошення
car.html                — сторінка звіту по авто
scripts/app.js          — логіка головної сторінки
scripts/car.js          — логіка сторінки авто
scripts/analysis.js     — виклик /api/analyze і показ аналізу оголошення
functions/api/analyze.js — бекенд (Cloudflare Pages Function): аналіз оголошення через Claude
styles/main.css         — стилі обох сторінок
data/engines.js         — каталог двигунів: родина, ГРМ, типові проблеми
data/gearboxes.js       — каталог коробок (MT5, MT6, DQ200, DQ250, DQ381, DQ400E, 09G, АКПП Mazda)
data/makes/skoda.js     — Škoda: модель → покоління → двигун → роки → коробки
data/makes/mazda.js     — Mazda: 3, 6, CX-5, CX-30
data/catalog.json       — список авто для бекенда (генерується з data/)
docs/korobky.md         — «яка коробка на яких моделях» (генерується з data/)
scripts/build-docs.js   — генератор docs/korobky.md і data/catalog.json
```

## Як працює вибір коробки

Користувач обирає лише **Механіка** чи **Автомат**. Конкретну коробку (наприклад, DQ200 чи DQ381) сайт визначає сам із `data/makes/*.js` за моделлю, поколінням, двигуном і роком. Якщо для комбінації можливі кілька коробок, у звіті показуються всі та пояснюється, як перевірити точно.

## Аналіз оголошення (Claude)

Користувач вставляє текст оголошення, бекенд `functions/api/analyze.js` надсилає його Claude разом зі списком авто з бази. Claude знаходить авто в базі й аналізує саме оголошення: пробіг, ціну, тривожні формулювання, питання до продавця. Факти про двигуни й коробки сайт бере з бази, а не від Claude. Якщо авто в базі немає, сайт повідомляє, що інформації поки немає.

Розгортання й налаштування ключа API — у [DEPLOY.md](DEPLOY.md).

## Як додати дані

- Нова марка: створити `data/makes/<марка>.js` за зразком `skoda.js` і підключити його в `index.html` та `car.html`.
- Новий двигун чи коробка: додати запис у `data/engines.js` або `data/gearboxes.js`.
- Після змін даних оновити згенеровані файли: `node scripts/build-docs.js`.

Дані попередні, зібрані з відкритих джерел, і потребують звірки.
