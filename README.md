# Car Check

Сайт для перевірки авто перед покупкою: користувач обирає марку, модель, рік, двигун і тип коробки (або вставляє посилання на оголошення) й отримує звіт з типовими проблемами двигуна та коробки.

## Структура

```
index.html              — головна сторінка: вибір авто, посилання або текст оголошення
car.html                — сторінка звіту по авто
scripts/app.js          — логіка головної сторінки
scripts/car.js          — логіка сторінки авто
scripts/analysis.js     — виклик /api/analyze і показ аналізу оголошення
functions/api/analyze.js — бекенд: аналіз оголошення через Claude
functions/api/otomoto.js — завантаження й розбір сторінки оголошення Otomoto
worker/index.js         — точка входу Cloudflare Worker (/api/analyze)
worker/limiter.js       — обмеження кількості аналізів (Durable Object)
scripts/listing-url.js  — перевірка, що посилання веде на конкретне оголошення
wrangler.jsonc          — налаштування Cloudflare Worker
styles/main.css         — стилі обох сторінок
data/engines.js         — каталог двигунів: родина, ГРМ, типові проблеми
data/gearboxes.js       — каталог коробок (MT5, MT6, DQ200, DQ250, DQ381, DQ400E, 09G, АКПП Mazda)
data/makes/skoda.js     — Škoda: модель → покоління → двигун → роки → коробки
data/makes/mazda.js     — Mazda: 3, 6, CX-5, CX-30
data/knowledge.json     — база для Claude: список авто, двигуни, коробки (генерується з data/)
docs/korobky.md         — «яка коробка на яких моделях» (генерується з data/)
scripts/build-docs.js   — генератор docs/korobky.md і data/knowledge.json
```

## Як працює вибір коробки

Користувач обирає лише **Механіка** чи **Автомат**. Конкретну коробку (наприклад, DQ200 чи DQ381) сайт визначає сам із `data/makes/*.js` за моделлю, поколінням, двигуном і роком. Якщо для комбінації можливі кілька коробок, у звіті показуються всі та пояснюється, як перевірити точно.

## Аналіз оголошення (Claude)

Користувач вставляє посилання на оголошення Otomoto. Бекенд (`functions/api/otomoto.js`) сам завантажує сторінку й бере з неї дані оголошення; якщо Otomoto сторінку не віддав, сайт просить вставити текст оголошення вручну. Далі `functions/api/analyze.js` надсилає оголошення Claude разом з базою знань сайту (`data/knowledge.json`). Якщо марки чи моделі з оголошення немає в базі, Claude не викликається. Claude знаходить авто в базі й оцінює саме цю пропозицію: загальний вердикт з балом, ціну відносно орієнтовного ринку, правдоподібність пробігу, повноту оголошення, технічні ризики цього екземпляра з урахуванням відомих проблем двигуна й коробки, очікувані витрати, тривожні ознаки й питання продавцю. Якщо авто в базі немає, сайт повідомляє, що інформації поки немає.

Посилання приймаються лише на конкретні оголошення Otomoto (не списки й не пошук). Кількість аналізів обмежена: 5 за 10 хвилин і 20 за добу з однієї IP-адреси та 300 на добу на весь сайт.

Розгортання й налаштування ключа API — у [DEPLOY.md](DEPLOY.md).

## Як додати дані

- Нова марка: створити `data/makes/<марка>.js` за зразком `skoda.js` і підключити його в `index.html` та `car.html`.
- Новий двигун чи коробка: додати запис у `data/engines.js` або `data/gearboxes.js`.
- Після змін даних оновити згенеровані файли: `node scripts/build-docs.js`.

Дані попередні, зібрані з відкритих джерел, і потребують звірки.
